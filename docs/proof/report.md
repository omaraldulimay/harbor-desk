3 tenants share one database (pool). Each has 20 tickets and a comment. 10000 random attempts ran as one tenant against the ids of another, through the real repositories and with hand written SQL, in 2878 ms.

| Attempt | Count | Leaks |
|---|---|---|

Reads returned no row, updates changed 0 rows, a comment on a foreign ticket and an insert with a foreign `tenant_id` were rejected by the database. A snapshot of all tickets and comments (ids, status, text) taken with the owner role before and after is identical.

**Query without `WHERE tenant_id`:** `select count(*) from tickets` as tenant A returns **20** rows. The same table holds **60** rows of these three tenants (owner view). Rows of other tenants visible to A: **0**.

Settings checked in `RlsTest`: app role has no superuser and no BYPASSRLS and owns no table, every table has RLS enabled and forced, an unset `app.tenant_id` shows no rows.
